Engine-created documents are written as `<pathKey>-<slug>.md` (e.g. `MEMO-0011-request-identity-follows-the-runtime.md`), slug derived from title by `core/document-slug.ts` (NFKD → ASCII, lowercase, hyphen runs, 60-char cap on a word boundary; empty → bare `<pathKey>.md`). The slug NEVER participates in identity, uniqueness, lookup, or links: `document-identity.ts` strips it, collisions key on the number, a bare and a slugged file for one key are a quarantined collision. Slug is frozen at creation — title edits never rename. Bare-number files coexist forever; no migration, no config flag. Never synthesize `docs/<folder>/<id>.md` paths by hand — address by id and read `sourcePath` from the entity.
