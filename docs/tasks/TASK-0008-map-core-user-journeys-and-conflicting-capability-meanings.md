## Research task

Start from NORTH-STAR and concrete reported friction. Map cold-open orientation, post-compaction recovery, finding a fact versus a document, recording/correcting knowledge, creating/completing work, authoring decisions, and maintaining memory.

For each journey identify the intended entry point, competing choices, surprising exclusions (including memories hidden from ordinary search/list), home selection, follow-up calls, and escape hatches. Examine available local usage/journal evidence and existing dogfood reports. Document instrumentation blind spots; absence from write-only logs is not evidence of no usage. Separate maintainer-only operations from recurring agent needs.

Deliverable: workflow/ambiguity matrix with concrete examples, evidence strength, proposed core jobs, and unresolved product questions. Completion: each capability has a demonstrated role or an explicitly unproven justification; no usage claims are invented.
